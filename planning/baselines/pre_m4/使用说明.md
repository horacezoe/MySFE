# 余烬行动 3D · 第四阶段试玩

离线、第一和第三人称的 3D 搜打撤原型。本轮加入灰湾转运站地图、三项营地任务、双撤离点和舒适/标准规则，保留搜索、格子背包、仓库、完整存档及枪械与守卫行为。

## 开始试玩

双击工作目录的 **[试玩第四阶段.bat](../试玩第四阶段.bat)**，或本目录的 [试玩.bat](试玩.bat)。启动器使用 F 盘已有 Godot 4.7.2，无需另装开发环境。

1. 在「营地行动简报」接受任务，选择舒适或标准规则，再打开仓库检查装备。新档默认舒适；已有对局的任务与难度锁定。
2. 点击「快速配装」，检查步枪、护具、备弹和药包，再出发。西侧补给区较安全，中央仓库有室内搜索点，东侧通信站风险更高。
3. 靠近橙色箱子按 E。每 0.7 秒揭示一件物品；选物品后「自动转移」，或「全部拾取」。关闭重开不会刷新掉落。
4. 按 M 查看地图、任务和撤离条件；按 B 管理背包。选中物品、调整数量可拆堆，旋转后点目标空格预览并确认；「整理」自动排布。
5. 普通出口「货运公路」在东南侧，到达后按 E 并停留 5 秒。「维修通道」在西南侧，需背包携带通信站箱子中的通行证，等待 3 秒；成功撤离消耗一张通行证。离开区域或失去通行证会取消倒计时。
6. 撤离后装备和物资进入仓库。回行动简报交付任务领取奖励，出售物资才另获资产。可在背包中「保存并回营地」，下次继续最近成功保存的对局。

## 任务和规则

| 任务 | 完成方式 | 奖励 |
| --- | --- | ---: |
| 补齐急救物资 | 在营地上交 2 件医疗物资；西侧补给箱可搜到 | 400 |
| 恢复前哨联络 | 接任务后到达东侧通信站终端，再成功撤离 | 500 |
| 清除仓区指挥官 | 接任务后击败通信站内标为「指挥官」的守卫，再成功撤离 | 700 |

三项任务各可交付一次，奖励不会重复发放。调查和击杀须在成功撤离后才能交付，阵亡不保留本局达成的任务进度；收集任务需要实际仓库物资，交付会扣除对应数量。

| 规则 | 时间与敌人 | 失败损失 |
| --- | --- | --- |
| 舒适 | 10 分钟；敌人伤害为标准的 65%，发现距离较短、反应较慢 | 保留身上已装备的步枪与护具，背包丢失 |
| 标准 | 6 分钟；标准战斗压力 | 身上装备和背包全部丢失 |

两种规则都保留仓库，搜索、背包和地图界面都会暂停世界。舒适模式保留装备当前弹匣和护甲耐久，不会补满；携带在背包而未装备的武器仍会丢失。规则在出发时锁定，继续对局不会切换规则。

背包为 **6×5 格、25 kg 上限**，仓库为 **10×12 格**。满包时剩余物品留在箱内；撤离时仓库放不下的物资进入「收件区」，整理后可取回。搜索和背包管理时暂停战斗与倒计时。

## 操作

| 操作 | 键鼠 |
| --- | --- |
| 移动 / 快跑 | WASD / 按住 Shift |
| 观察 / 开火 | 首次点击锁定鼠标；移动鼠标观察，再按左键开火 |
| 瞄准 | 按住右键，或 X 切换 |
| 跳跃 / 蹲下起身 | 空格 / C |
| 第一、第三人称 | V |
| 换弹 / 治疗 | R / Q |
| 搜索撤离 / 背包 / 地图任务 | E / B / M |
| 暂停或关闭库存界面 | Esc |

触屏保留左侧移动、右侧观察和独立开火手指。库存采用「选物品 → 点目标格 → 确认」，无需依赖拖拽；两侧「上移/下移」可翻看仓库。

行动中装备锁定，结算后回营地更换。枪内弹药随步枪保存，备弹和药包是真实物品；换弹和治疗完成才消耗，开火可取消治疗并保留药包。护甲损耗会带回仓库，当前没有维修功能。

阵亡、超时或主动「放弃上局」都按本局规则结算损失，营地仓库保留。失去全部步枪后，可通过「快速配装」领取不可出售的救济装备继续玩。仓库物资可出售，药包和弹药可用资产购买。

## 存档

Windows 源码试玩使用本项目的 `user_data/saves/`，正式槽为 `profile_A.json`、`profile_B.json`。备份时先退出游戏，再复制整个目录。正式导出及移动端默认使用 Godot 的 `user://saves`。

每 10 秒、物品操作、搜索揭示、换弹治疗完成、暂停和正常关窗时保存。强制结束后恢复最近一次成功检查点，未保存的几秒动作可能回退。保存内容包括仓库、配装、货币、对局、位置姿态、生命护甲、药弹、装填治疗、敌人状态、箱内物品及搜索进度；导航路径重建，感知重新采样。

一份损坏时尝试恢复另一份；两份都坏、版本较新或出现未知物品时停止写入并保留文件。写入失败会提示，失败的库存操作不发布。多个窗口使用同一存档时，旧窗口不能覆盖另一个窗口的新进度。

新存档不存在时才迁移旧 `user://progress.json` 的财富和成功次数；旧文件保留，新目录另留备份。初始物资不会反复发放。

## 练习与设备

营地点「关闭」进入菜单，可选静态靶场或双守卫演练。[试玩第一阶段.bat](../试玩第一阶段.bat) 和 [试玩第二阶段.bat](../试玩第二阶段.bat) 继续直接进入对应练习。练习不消耗仓库、不结算奖励，也不覆盖待续的普通对局。

当前提供 **Windows 试玩和 Godot 源码，还不是已签名的 iPad 安装包**。横屏和模拟多指已检查，iPad 真机手感、后台恢复、安全区和持续性能仍待验收。地图本轮加入原创建筑、室内搜索、分区道路和掩体；人物、枪械仍是程序化模型，正式骨骼动画、美术和设备优化留在后续阶段。

旧第三阶段存档会先备份再升级。未完成的旧对局继续原地图、原规则和原倒计时；完成或放弃后，下一局进入灰湾转运站。旧物品和财富不会重新初始化。
