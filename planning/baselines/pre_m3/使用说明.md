# 余烬行动 3D · 第三阶段试玩

离线、第一和第三人称的 3D 搜打撤原型。本轮完善搜索、格子背包、营地仓库和中断续玩，保留第二阶段枪械与守卫行为。

## 开始试玩

双击工作目录的 **[试玩第三阶段.bat](../试玩第三阶段.bat)**，或本目录的 [试玩.bat](试玩.bat)。启动器使用 F 盘已有 Godot 4.7.2，无需另装开发环境。

1. 在营地点「快速配装」，检查步枪、头盔、防弹衣及弹药药包，再「进入封锁区」。有未完成的对局时，点击「继续上局」。
2. 靠近橙色箱子按 E。每 0.7 秒揭示一件物品；选物品后「自动转移」，或「全部拾取」。未揭示的物品不能领取，关闭重开不刷新掉落。
3. 按 B 打开背包。选中物品、调整数量可拆堆；旋转后点目标空格预览，再确认放置。「整理」自动重新排布。
4. 到绿色区域按 E 并停留 5 秒，装备和物资进入仓库。**物资不会自动换钱**，在仓库出售后才增加资产。
5. 中途可在背包中「保存并回营地」，或暂停后保存返回。下次继续上局会恢复最近成功保存的进度。

背包为 **6×5 格、25 kg 上限**，仓库为 **10×12 格**。满包时剩余物品留在箱内；撤离时仓库放不下的物资进入「收件区」，整理后可取回。搜索和背包管理时暂停战斗与倒计时。

## 操作

| 操作 | 键鼠 |
| --- | --- |
| 移动 / 快跑 | WASD / 按住 Shift |
| 观察 / 开火 | 首次点击锁定鼠标；移动鼠标观察，再按左键开火 |
| 瞄准 | 按住右键，或 X 切换 |
| 跳跃 / 蹲下起身 | 空格 / C |
| 第一、第三人称 | V |
| 换弹 / 治疗 | R / Q |
| 搜索撤离 / 背包 | E / B |
| 暂停或关闭库存界面 | Esc |

触屏保留左侧移动、右侧观察和独立开火手指。库存采用「选物品 → 点目标格 → 确认」，无需依赖拖拽；两侧「上移/下移」可翻看仓库。

行动中装备锁定，结算后回营地更换。枪内弹药随步枪保存，备弹和药包是真实物品；换弹和治疗完成才消耗，开火可取消治疗并保留药包。护甲损耗会带回仓库，当前没有维修功能。

阵亡、超时或主动「放弃上局」会丢失本局装备和背包，营地仓库保留。失去全部步枪后，可通过「快速配装」领取不可出售的救济装备继续玩。仓库物资可出售，药包和弹药可用资产购买。

## 存档

Windows 源码试玩使用本项目的 `user_data/saves/`，正式槽为 `profile_A.json`、`profile_B.json`。备份时先退出游戏，再复制整个目录。正式导出及移动端默认使用 Godot 的 `user://saves`。

每 10 秒、物品操作、搜索揭示、换弹治疗完成、暂停和正常关窗时保存。强制结束后恢复最近一次成功检查点，未保存的几秒动作可能回退。保存内容包括仓库、配装、货币、对局、位置姿态、生命护甲、药弹、装填治疗、敌人状态、箱内物品及搜索进度；导航路径重建，感知重新采样。

一份损坏时尝试恢复另一份；两份都坏、版本较新或出现未知物品时停止写入并保留文件。写入失败会提示，失败的库存操作不发布。多个窗口使用同一存档时，旧窗口不能覆盖另一个窗口的新进度。

新存档不存在时才迁移旧 `user://progress.json` 的财富和成功次数；旧文件保留，新目录另留备份。初始物资不会反复发放。

## 练习与设备

营地点「关闭」进入菜单，可选静态靶场或双守卫演练。[试玩第一阶段.bat](../试玩第一阶段.bat) 和 [试玩第二阶段.bat](../试玩第二阶段.bat) 继续直接进入对应练习。练习不消耗仓库、不结算奖励，也不覆盖待续的普通对局。

当前提供 **Windows 试玩和 Godot 源码，还不是已签名的 iPad 安装包**。横屏和模拟多指已检查，iPad 真机手感、后台恢复、安全区和持续性能仍待验收。地图、人物与枪械沿用原创程序化模型，任务、多类出口、正式美术及设备优化留在后续阶段。

详细记录见 [第三阶段报告](docs/PHASE3_REPORT.md)，后续约定见 [技术设计](docs/TECHNICAL_DESIGN.md)。
