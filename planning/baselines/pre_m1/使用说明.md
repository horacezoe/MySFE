# 余烬行动 3D · 第一阶段试玩

离线、第一和第三人称的 3D 搜打撤原型。本轮重点修正操作、观察和瞄准，人物与枪械仍为程序化模型。

## Windows 开始试玩

双击工作目录中的 **[试玩第一阶段.bat](../试玩第一阶段.bat)**，直接进入靶场；也可双击本目录的 **[试玩.bat](试玩.bat)**，从菜单选择“靶场练习”或“进入封锁区”。启动器使用 F 盘已有的 Godot 4.7.2。

| 操作 | 键鼠 |
| --- | --- |
| 移动 / 快跑 | WASD / 按住 Shift |
| 观察 / 开火 | 首次点击画面锁定鼠标；移动鼠标观察，再按左键开火 |
| 跳跃 / 蹲下或起身 | 空格 / C |
| 第一、第三人称切换 | V |
| 换弹 / 治疗 | R / Q |
| 搜索或撤离 | E |
| 暂停 / 返回操作 | Esc；搜索界面中按 Esc 关闭搜索 |

首次点击只锁定鼠标，不会误射。暂停后可调整“观察灵敏度”滑条或 ± 按钮；恢复后重新按下移动、开火等操作。

## 建议先这样试

1. 在靶场起点分别瞄准 5、15、40 米靶标，按 V 切换视角，观察命中标记和伤害数字。靶标不会攻击，击倒后自动复位。
2. 走到标有“薄墙”的测试区，贴近墙面举枪。出现“枪口受阻”时不能开火，也不扣弹；后退后再试。
3. 到低顶通道按 C 蹲行，尝试起身和跳跃；顶上空间不足会拒绝起身，离开后可正常站起、跳落。
4. 按 Esc 暂停，选择“结束本局，返回营地”，再进入封锁区体验搜索与撤离。

封锁区中，靠近橙色补给箱按 E，逐件或全部拾取；搜索时战斗和计时暂停。到绿色撤离区按 E 并停留 5 秒，成功后结算本局物资。失败或主动返回营地会放弃本局拾取物资。靶场不结算奖励，不改写仓库进度。

## 触屏与 iPad

目标操作为横屏：左侧拖动移动、右侧拖动观察，第三根手指按住“开火”；跳跃、蹲下、快跑等使用屏幕按钮。移动和观察触点越过屏幕中线后仍保持原职责。

当前提供 Windows 试玩和 Godot 源码，**还不是已签名的 iPad 安装包，也未做 iPad 真机测试**。自动测试中的多指输入由 `Viewport.push_input` 模拟，不能据此宣称平板手感或性能已经验收。iOS 构建与安装后续仍需 Mac、Godot 导出模板及 Xcode，见 [Godot 官方 iOS 导出说明](https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_ios.html)。
