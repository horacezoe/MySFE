# 余烬行动 3D · 第二阶段试玩

离线、第一和第三人称的 3D 搜打撤原型。本轮完善枪械命中、护甲和守卫行为，并新增可重复的双守卫演练；人物、枪械和地图仍为原创程序化模型。

## Windows 开始试玩

双击工作目录中的 **[试玩第二阶段.bat](../试玩第二阶段.bat)**，直接进入“战斗演练”。本目录的 **[试玩.bat](试玩.bat)** 打开菜单，可选择普通封锁区、静态靶场或双守卫演练；原 [试玩第一阶段.bat](../试玩第一阶段.bat) 继续直接进入静态靶场，但运行的是当前版本。启动器使用 F 盘已有的 Godot 4.7.2。

| 操作 | 键鼠 |
| --- | --- |
| 移动 / 快跑 | WASD / 按住 Shift |
| 观察 / 开火 | 首次点击画面锁定鼠标；移动鼠标观察，再按左键开火 |
| 瞄准 | 按住右键，或按 X 切换；触屏点击“瞄准” |
| 跳跃 / 蹲下或起身 | 空格 / C |
| 第一、第三人称切换 | V |
| 换弹 / 治疗 | R / Q |
| 搜索或撤离 | E |
| 暂停 | Esc；搜索界面中按 Esc 关闭搜索 |

首次点击只锁定鼠标，不会误射。暂停菜单可调观察灵敏度、重开演练或返回营地；恢复后需重新按下移动、开火等操作。

## 建议先试战斗演练

1. 出生时先看中央掩体。左右都能绕行，两名守卫有各自巡逻路线。
2. 靠近后观察头顶状态：发现动静、准备射击、交战、搜索中。敌人发现你后会先准备，并受视线和枪口遮挡约束。
3. 在掩体旁开枪后换一个位置，观察守卫调查枪声位置；躲回墙后，观察其到最后发现的位置搜索，找不到后返回巡逻。
4. 分别尝试站立腰射、移动射击、蹲下和瞄准。移动与空中更分散，瞄准更集中；空中无法进入瞄准状态。
5. 试射头部、躯干和四肢，观察部位、生命损失与护甲损失。HUD 同时显示自己的头盔和背心耐久。
6. 受伤后按 Q 治疗。持续 2.2 秒后才消耗一个药包并恢复生命；按开火会中断治疗并保留药包。治疗不修复护甲。

演练不会结算仓库奖励或损失。击败两名守卫即完成，可按 Esc 选择“战斗演练”重新开始；倒下后也可再次选择演练。

## 靶场与搜打撤

静态靶场保留 5、15、40 米靶位、薄墙和低顶通道。靶标不会攻击，击倒后复位；换弹补充练习备弹。两种视角都从实际枪口结算命中：贴墙出现“枪口受阻”时不射击、不扣弹；枪口有效但前方有墙时会正常消耗一发并击中墙面。

普通封锁区中，靠近橙色补给箱按 E，逐件或全部拾取；搜索时战斗和计时暂停。到绿色撤离区按 E 并停留 5 秒，成功后结算本局物资。失败或主动返回营地会放弃本局拾取物资。普通封锁区保留原财富与撤离次数存档，本轮没有迁移存档格式。

## 触屏与 iPad

目标操作为横屏：左侧拖动移动、右侧拖动观察，第三根手指按住“开火”；瞄准、跳跃、蹲下、快跑等使用屏幕按钮。移动和观察触点越过屏幕中线后仍保持原职责。

当前提供 Windows 试玩和 Godot 源码，**还不是已签名的 iPad 安装包，也未做 iPad 真机测试**。自动测试中的多指输入由 `Viewport.push_input` 模拟，不能代替平板手感、后台恢复或持续性能验收。iOS 构建与安装后续仍需 Mac、Godot 导出模板及 Xcode，见 [Godot 官方 iOS 导出说明](https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_ios.html)。

## 当前范围

已接入单枪共享战斗规则、头胸肢体命中、简化防护、瞄准与散布，以及单种守卫的巡逻、感知、调查、搜索和静态地图绕障。导航针对当前单层场景；尚无动态门、多层导航、小队协同和复杂掩体战术。人物动作和瞄具仍是原型表现，正式骨骼模型、光学瞄具和美术替换属于后续阶段。
