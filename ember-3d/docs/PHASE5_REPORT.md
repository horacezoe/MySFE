# 第五阶段：人物、枪械与动作表现样板

构建 `phase5-20261106`，2026-11-06。对应技术文档 M4 的“一名角色、一把步枪”表现样板。交付 Windows 可玩工程与直接进入靶场的第五阶段启动器；原有搜打撤、任务、背包仓库和存档继续可用。

## 本轮变化

人物从方块拼装替换为原创蒙皮网格，采用成人比例、19 根骨骼、连续衣物轮廓、迷彩织物、头盔护目镜、面罩、战术背心、弹袋、背包、手套和靴子。站立、移动、快跑、蹲行、跳跃落地、持枪、装填及倒地分别响应现有逻辑状态。蹲下由髋膝踝弯曲完成，Visual 始终保持单位缩放。

步枪增加倒角机匣、护木导轨、枪管、枪托、扳机护圈、曲面弹匣、拉机柄与开放红点瞄具。第一人称有双手、分节手指和衣袖；换弹按逻辑进度完成摘匣、移出、插入、拉机柄和回握。第三人称左手跟随同一套弹匣/机柄目标点。开火有后坐、枪机与短枪口闪光。

瞄准时使用真实 Aim 定位点对齐相机轴，第一人称隐藏常驻 HUD 十字以显示模型里的红点；命中反馈仍保留。自由转向、上下瞄准、第三人称相机避墙和真实枪口遮挡沿用原有规则。新模型的 Muzzle 继续用于射线起点，不以枪身外观替代伤害计算。

增加分层枪声、距离衰减的守卫枪声/脚步、玩家脚步及装填机械声。曳光、命中火花和弹壳改为固定池复用。声音有固定声部数及每声部每帧一次启动预算；压力下只省略超预算声音，不改变命中或弹药。

方向光加入有限距离阴影并调整曝光，便于辨认人物和枪身轮廓。地图结构仍是第四阶段的灰湾转运站。

## 模块与数据边界

| 模块 | 职责 |
| --- | --- |
| `CharacterVisual` | Skeleton3D / Skin / 合并 ArrayMesh；AnimationTree 混合胸头片段；双节 IK 驱动四肢；提供本地骨架关键点 |
| `RifleVisual` | 枪械/双手网格、固定定位点、可定位到任意装填进度的表现；不修改根瞄准变换 |
| `CombatFeedback` | 共享声音缓存、固定特效池与声部预算；由主循环显式推进 |
| `CombatResolver.sync_visual_pose` | 头胸和八段肢体的命中区域跟随骨架；蹲下不再统一压扁碰撞形状 |
| `RaidSnapshot` | 继续使用已有逻辑状态重建蹲姿、装填、治疗和倒地；不保存网格或动画资源 |

PlayerMotor 仍唯一控制移动，WeaponController 仍唯一结算弹药，HealthState 仍唯一结算生命和护甲。暂停、搜索、背包及地图打开后，动作时钟和特效生命周期停止。恢复姿势使用显式 seek，不推进装填或重复给弹药。死亡时碰撞与 AI 立即停用，尸体动作继续短暂完成并保持终态，枪随身体倒下。

本轮不更改存档 schema、物品身份、背包容量、掉落规则和任务奖励。第三、第四阶段保存迁移与失败保护继续保留。开发前备份在 `planning/baselines/pre_m4`。

## 验证

完整聚合回归 **24/24 套件通过**，包括前四阶段的操作、命中、AI、库存、磁盘存档、任务、撤离和旧对局兼容。之后对最终人物几何、双视角装填与音频预算修正又做了针对性复查。测试使用内存 profile 或独立磁盘夹具，不修改个人进度。

- 角色独立检查 1,759 项：绑定权重、骨架有效性、走跑蹲跳/倒地、冻结、恢复、网格预算；按实际蒙皮顶点验证深蹲能通过 1.28 米净空，尸体不沉到地面下。
- 步枪独立检查 145 项：真实 Marker、可定位装填、双手、闪光生命周期、根变换与资源预算。
- 反馈独立检查 77 项：重复 100 发不增加节点、效果到期、声音缓存、暂停停止、有限变换。
- 整场景集成检查 99 项，覆盖 FP/TP 枪口、ADS 光学点居中、头/八段肢体同步、深蹲双手握点、站立/深蹲装填四阶段左手与实际枪械目标误差小于 3 厘米、装填暂停与一次结算、背包冻结、读档姿势复原、尸体和多轮 100 发压力。
- 实际 GPU 渲染检查了第一人称、第三人称、ADS、装填、深蹲、近看角色和普通地图。可通过 `tests/capture_phase5.gd` 复现，截图保存在 `tests/phase5_*.png`。

### 桌面样本开销

相同靶场、玩家与三个可见靶标、1280×800、兼容渲染器、关闭垂直同步，预热后采样 8 秒。设备为 NVIDIA GeForce RTX 5060 Laptop GPU。记录在 `phase5_performance.log` 和 `phase4_performance_baseline.log`，脚本为 `tests/benchmark_presentation.gd`。

| 指标 | 第四阶段基线 | 第五阶段样板 |
| --- | ---: | ---: |
| 平均帧率 | 947.7 | 614.8 |
| 第 95 百分位帧时间 | 1.314 ms | 2.114 ms |
| 游戏步进平均 CPU 耗时 | 0.140 ms | 0.520 ms |
| 最大 draw calls | 180 | 261 |
| 最大渲染 primitives | 38,792 | 73,304 |

新蒙皮、阴影和细节有可测的成本，桌面样本仍有足够的 60 FPS 余量；这不是 iPad 性能结论，也不是长时间温控压力测试。M5 需做移动端分档、远处角色更新频率/LOD、阴影预算与持续帧时验证。

## 试玩

双击项目上一级的 `试玩第五阶段.bat` 进入无损失靶场。V 切换视角，右键或 X 瞄准，R 换弹，C 蹲下，Shift 快跑，空格跳跃。先开几枪再换弹，便于观察完整装填动作。暂停后可回营地进入完整搜打撤；`ember-3d/试玩.bat` 仍是普通营地入口。

## 保留限制与后续

本轮是原创程序化制作的骨骼/枪械样板，面部、衣物褶皱、手部细节和动作过渡仍简化；AnimationTree 胸头片段加 IK 不等同于完整动捕动画库。红点是模型内自发光点，并非有视差补偿的完整光学模拟。尚未增加枪械改装、多枪型、布料/布娃娃模拟或扫描材质。

仍交付 Windows 工程，尚无签名 iPad 安装包。后续依照 M5 验证 iPad 横屏触控、后台/恢复、设备持续性能、存储及安装签名，再决定扩充高精度资产。

实现接口参考 Godot 官方 [AnimationTree](https://docs.godotengine.org/en/stable/tutorials/animation/animation_tree.html)、[ArrayMesh](https://docs.godotengine.org/en/stable/tutorials/3d/procedural_geometry/arraymesh.html)、[Skin](https://docs.godotengine.org/en/latest/classes/class_skin.html) 文档。资产来源、单位、贴图与预算见[资产清单](ASSET_MANIFEST.md)。
